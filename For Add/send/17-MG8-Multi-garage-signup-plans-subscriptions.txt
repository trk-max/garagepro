DECISIONS ALREADY MADE (do not re-ask; tell me only if one is impossible or dangerous):
1. Customers: BOTH independent garages (fully isolated from each other) AND owners with several branches.
   Data model: Organisation (the owner / customer account) → one or more Branches (garages).
   Independent garage = an organisation with one branch.
2. Shared between branches of the SAME organisation (never between organisations):
   - Clients and vehicles, with the full repair history from all branches (each order shows its branch).
   - Settings and prices: services, hourly rate, VAT, templates, inspection models, message templates, labour catalogue
     are set at organisation level and can be overridden per branch.
   - Stock: each branch has its own stock; add stock TRANSFERS between branches (request → send → receive, with stock
     movements on both sides, in-transit state, printable transfer note, audit log).
   NOT shared: staff. Each employee belongs to one branch (time clock, leave, contracts, skills per branch).
   The organisation owner/admin can see and manage all branches.
3. Access: each organisation has its own subdomain (e.g. garage-ali.garagepro.tn) with its own name, logo and colours on
   the public client site, tracking, booking, showroom and printed documents. Custom domains optional later (plan for it).
   Branch chosen on the client site when the organisation has several (booking, tracking, contact).
4. Sign-up and paid subscriptions FROM THE START: online sign-up, free trial, plans with limits (branches, users,
   storage, SMS/AI usage), monthly/yearly payment through Konnect and/or Flouci (Tunisia), invoices for the subscription,
   reminders before expiry, grace period, then read-only mode (never delete data; export always possible).
   A SUPER-ADMIN space (me only) to see organisations, plans, payments, usage, extend trials, suspend, impersonate with
   audit log.
   PLANS ARE THE OFFERS of For Add/plans/PLAN-LAVAGE-ATELIER.md and For Add/plans/PLAN-SAAS.md: Atelier Lite, Lavage, Lavage + Atelier,
   Complet. A plan = a preset of the module switches of prompt W0 (For Add/prompts/PROMPTS-WASH.md) + limits; options
   (subscriptions/loyalty, mobile washing, plate camera, e-invoicing, extra WhatsApp/SMS/AI credits, extra branch, extra
   users) are sold as add-ons. Modules are switched per BRANCH (one branch can be Lavage, another Atelier) and the plan
   price is per branch. The plan catalogue (prices in TND, monthly/yearly, limits, add-ons) is edited by the super-admin,
   never hard-coded. Changing plan switches modules immediately; downgrading hides modules but keeps their data.
5. Offline hub: OPTIONAL. New organisations work online only. A branch that asks for it can get a hub; a hub holds only
   its branch's data plus the shared clients/vehicles/settings of its organisation, and syncs only that.
6. Numbering: per branch, with a branch prefix (e.g. TUN-F2026-0001, SFX-F2026-0001) for invoices, credit notes,
   quotes, orders, purchase orders, receipts, tickets. Each branch has its own legal identity (company name, tax ID,
   address, stamp duty settings) on its documents.
7. Existing data: my current garage becomes organisation #1 / branch #1, same accounts, same numbering continued,
   same tracking codes and QR links still working, hub still working.
